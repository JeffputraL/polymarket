Crypto Prediction Market Platform

A modern crypto-based prediction market platform inspired by Polymarket, built with an automated profit-sharing algorithm and fully autopilot system management.

This platform allows users to participate in prediction-based trading using cryptocurrency, while the system automatically manages market distribution, winner allocation, and owner revenue calculations in real-time.

Main Features
- Crypto Prediction Market System
- Automatic Winner Distribution
- 70% User Winning Allocation
- 30% Owner/Platform Allocation
- Fully Automated (Autopilot) System
- Real-Time Market Management
- Modern Dashboard Interface
- Secure Transaction Processing
